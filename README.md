# 📚 Book-Tracker

**Автор:** Вишняков Александр (Commbain)

## Описание
Консольное приложение для управления списком прочитанных книг с использованием паттерна MVC, хранением данных в JSON и историей действий.

## Функционал
- ✅ Добавление, редактирование, удаление книг
- ✅ Фильтрация по жанру и количеству страниц
- ✅ История действий (стек/очередь)
- ✅ Отмена последнего действия
- ✅ Сохранение данных в JSON
- ✅ Валидация ввода

## Технологии
- Python 3.9+
- JSON для хранения данных
- MVC архитектура
- ООП (инкапсуляция, наследование, полиморфизм)
